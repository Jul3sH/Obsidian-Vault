# Choosing a Decision Framework

## Purpose

The picker for Julian's decision frameworks: which one to use, and when to move from one to the next. It exists so that choosing a framework takes seconds, not longer than the decision itself (the ADHD analysis-paralysis risk).

Sections: The Path · Framework Comparison · Tools · Key Takeaways · Links · Document Log

## The Path

**Start every decision with [[first-decision-framework|FIRST]]** (Facts, Issue, Repercussions, Scenarios, Then). It takes minutes and validates an action about to be taken. Escalate only when a signal below says so.

| Signal | Use |
|--------|-----|
| The issue fits in a sentence, the choice can be undone or is modest, an answer is needed today | [[first-decision-framework\|FIRST]] |
| Not sure what you are actually deciding | [[first-decision-framework\|FIRST]] steps 1-2 (Facts, Issue) until the issue fits in a sentence |
| Getting it wrong is expensive or hard to undo, the issue will not fit in a sentence, or the decision earns a journal entry | [[braind-framework\|BRAIND]] |
| Complex or multi-dimensional, or dependent on terms not yet met | [[braind-framework\|BRAIND]] with its complex-decision methods (workstream split, clarified intuition, conditions and dependencies) |
| BRAIND is not enough: many options need researching and weighing side by side, with time available | [[seven-step-decision-process\|Seven-step process]] |

**BRAIND is the default for any journalled decision.** A journalled decision run in anything else records why in its entry.

**Irreversible means escalate, whatever the time pressure.** Career moves, financial commitments and relationship endings go to BRAIND even when FIRST feels enough. Otherwise, when in doubt, stay with FIRST: a committed next step in five minutes beats a perfect decision never made. Most decisions are more reversible than they feel; test that before escalating.

## Framework Comparison

| | [[first-decision-framework\|FIRST]] | [[braind-framework\|BRAIND]] | [[seven-step-decision-process\|7-step]] |
|--|--|--|--|
| **Speed** | Minutes | An hour to days, depending on complexity | Hours to days |
| **Best for** | Validating one action, now | One option in depth, pre-commitment, locked | Many options researched and weighed |
| **Covers alternatives?** | No | Yes (A) | Yes |
| **Covers second-order effects?** | Yes, the 10-10-10 step | Through R and I | Yes |
| **Covers next steps?** | Yes (Then) | No - pair with FIRST step 5 | Yes |
| **Covers review/learning?** | No | No | Yes |
| **ADHD-friendly?** | High | Medium | Low (without structure) |

## Tools (run inside any framework)

- [[belief-assumption-testing|Belief & Assumption Testing]] - label each load-bearing claim Fact, Assumption or Belief, then clear or test it.
- [[counterfactual-questioning|Counterfactual Questioning]] - find which factor is driving a gut feeling by removing one at a time.

## Key Takeaways

- One path: FIRST first, BRAIND when the stakes, irreversibility or a journal entry call for it, the seven-step process only when BRAIND is not enough.
- Analysis paralysis is itself a decision (to do nothing). Treat it as one.
- No framework covers everything: FIRST skips alternatives, BRAIND skips execution, the seven-step process skips speed.
