# MM: Guard the Critical Path

This is the Guard the Critical Path mental model: protecting the highest-consequence,
irreversible items from the busywork that keeps crowding them out. It exists because
being busy and being on the critical path are not the same thing, and the gap between
them is where the expensive misses happen. Read it whenever firefighting or a long
list is competing for the same hours as something irrevocable. The full detail lives
in [[prioritisation-and-scheduling]].

**One-liner:** Firefighting is optional; the critical path is not.

**Reach for it when:** you're busy but not sure the busy-ness is on the thing that
actually can't be undone if you get it wrong.

## Key Takeaways

- Firefighting doesn't make critical-path work disappear, it just delays the
  reckoning.
- Irrevocable, high-consequence items get guarded daily, not reviewed when there's
  time.
- Reprioritise the moment new information changes what matters; staying locked into
  the old plan is rigidity, not discipline.
- A list of three achievable priorities beats a list of six aspirational ones.

## Principles

- **Ask what can't be undone.** The critical path is the set of activities where
  getting it wrong is irreversible; find them before anything else gets attention.
- **Firefighting is a choice, not a fact.** It feels urgent and unavoidable in the
  moment; it's usually optional relative to what's actually irrevocable.
- **Reprioritise immediately on new information.** A plan you're locked into for
  its own sake is no longer discipline.
- **Review scheduled priorities daily**, not just a glance at the diary, so a new
  request can be weighed against what's already committed.
- **Reduce the list to three.** Six daily tasks with one or two completed is a
  broken system; three achievable ones build momentum.

## Guidelines

- Before agreeing to absorb something urgent-feeling, ask whether it threatens the
  critical path or is just noise competing for the same hours.
- Test critical dependencies early, don't assume they'll work because there's time
  left before they're needed.
- Treat meetings that are genuine opportunities to shine as critical path too, and
  prepare for them accordingly, however busy the week is.
- Spread a weekly review across the weekend rather than leaving it to Sunday night.

## Limitations

This model protects time, not judgement, it doesn't tell you which activities
actually belong on the critical path, only that whatever does belongs ahead of
firefighting. It also doesn't address prioritising by cost versus interest, that
distinction is covered separately in [[mm-price-the-priority]].
